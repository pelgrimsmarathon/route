# Pelgrimsmarathon – routeplanner

Web-app om marathonetappes (42,195 km) langs de officiële pelgrimsroute naar Santiago de Compostela uit te zetten
en als GPX te delen met WorkOutDoors op de Apple Watch.

Live: https://route.pelgrimsmarathon.nl

## Opbouw

- `index.html` – de complete app
- `manifest.webmanifest` – maakt er een app van voor het beginscherm
- `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` – app-iconen
- `CNAME` – eigen domein

Gepubliceerd via GitHub Pages (branch `main`, map `/`).
